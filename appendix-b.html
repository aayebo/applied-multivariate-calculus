Appendix B. Introduction to Python and Jupyter

Learning. After completing this appendix, you should be able to install and use Python in JupyterLab or Jupyter Notebook; distinguish notebooks from reusable scripts; work with numerical data and arrays; write reliable functions; visualize curves, surfaces, and vector fields; compute derivatives, integrals, and optimizers; implement numerical methods for ordinary and partial differential equations; and reproduce representative calculations from Chapters 1–8. Throughout, you will connect each computational result to its mathematical justification.

The role of Python in this textbook

Python is a general-purpose programming language. The scientific Python ecosystem supplies numerical arrays (NumPy), plotting (Matplotlib), symbolic algebra (SymPy), numerical algorithms (SciPy), and data tables (pandas). Jupyter is an interactive environment for writing code, explanatory text, equations, and figures in a single notebook. These are different components: Python executes the program; Jupyter provides one convenient interface.

The guiding sequence is derive, implement, verify, interpret. For example, to compute the curvature of a space curve, first establish the formula \(\kappa=\|\boldsymbol{r}'\times\boldsymbol{r}''\|/\|\boldsymbol{r}'\|^3\), then write code, check it against a known case, and explain the geometry. A numerical output is evidence about a computation, not a proof of a mathematical identity.

Understanding the notebook interface

A Jupyter notebook is a file ending in .ipynb. Code cells execute Python, while Markdown cells hold prose and mathematical notation. Run a cell with Shift+Enter. A number beside a cell records execution order, not its location on the page. Notebook variables persist in the active kernel, so running cells out of order can produce misleading results. To test reproducibility, restart the kernel and run all cells from the beginning.

Checkpoint. Create a notebook named first_steps.ipynb. Add a Markdown cell describing the dot product and a code cell computing np.dot([1,2,3],[4,5,6]). Restart the kernel and run all cells. Record the result and explain why the restart matters.

A reproducible folder structure

Use a project folder with notebooks/, scripts/, data/, figures/, and results/. Store reusable numerical functions in scripts/ and use notebooks to develop explanations and visualizations. Avoid hard-coded personal file paths. Record package versions with python -m pip freeze or a curated requirements file. Share the source notebook as well as exported figures and conclusions.

Floating-point arithmetic and validation

Decimal numbers generally cannot be represented exactly in binary floating point. Instead of asserting 0.1+0.2 == 0.3, use np.isclose(0.1+0.2,0.3). For arrays, use np.allclose. State a tolerance that is appropriate for the scale of the problem. Avoid confusing rounding the display with improving the accuracy of a calculation.

Arrays, indexing, broadcasting, and linear algebra

Vectors and arrays

PythonDownload
import numpy as np
v = np.array([2.0, -1.0, 4.0])
w = np.array([1.0, 3.0, -2.0])
print(v[0])              # first entry: Python indexing starts at 0
print(v + w)             # componentwise sum
print(3 * v)             # scalar multiplication
print(np.dot(v, w))      # scalar dot product
print(np.cross(v, w))    # cross product in R^3
print(np.linalg.norm(v)) # Euclidean norm

Unlike ordinary Python lists, NumPy arrays support elementwise arithmetic. The expression v*w multiplies corresponding components; np.dot(v,w) computes their dot product. NumPy uses zero-based indexing: v[0] is the first component, whereas R uses v[1]. A slice v[0:2] includes indices 0 and 1 but excludes 2.

Matrices and systems of equations

For \(A\boldsymbol{x}=\boldsymbol{b}\), solve the system with a factorization-based routine rather than explicitly computing \(A^{-1}\).

PythonDownload
A = np.array([[3.0, 1.0], [1.0, 2.0]])
b = np.array([9.0, 8.0])
x = np.linalg.solve(A, b)
print(x)                 # [2., 3.]
print(np.allclose(A @ x, b))
print(np.linalg.det(A))
print(np.linalg.eigvalsh(A))

The @ operator performs matrix multiplication. A*B performs elementwise multiplication. A matrix with shape (m,n) has \(m\) rows and \(n\) columns; A.T transposes a matrix. Broadcasting allows arrays with compatible shapes to interact, but an accidental mismatch may produce a plausible-looking wrong result. Check shape before trusting a calculation.

Functions, loops, conditionals, and reusable code

PythonDownload
def unit_vector(v):
    """Return v/||v|| for a nonzero numerical vector."""
    v = np.asarray(v, dtype=float)
    magnitude = np.linalg.norm(v)
    if magnitude == 0:
        raise ValueError("The zero vector has no unit direction")
    return v / magnitude

print(unit_vector([3, 4, 0]))

A def statement introduces a function. The indented body defines its work; return sends the result to the caller. Use functions for repeated calculations and test edge cases such as zero-length vectors, invalid domains, and singular matrices. A for loop is useful for iterations, although vectorized array operations are often clearer and faster.

PythonDownload
def partial_x(f, x, y, h=1e-5):
    return (f(x+h, y) - f(x-h, y)) / (2*h)

f = lambda x, y: x*x*y + np.sin(y)
print(partial_x(f, 2.0, 0.5))

The central difference is \([f(x+h,y)-f(x-h,y)]/(2h)\) and has \(O(h^2)\) truncation error when \(f\) is sufficiently smooth. Extremely small \(h\) can increase floating-point cancellation. Numerical differentiation is an approximation; symbolic differentiation or an analytical derivative is preferable when available.

Symbolic differentiation and multivariable calculus with SymPy

NumPy evaluates expressions numerically. SymPy can manipulate exact symbolic expressions when an exact representation exists.

PythonDownload
import sympy as sp
x, y, t = sp.symbols("x y t", real=True)
f = x**2*y + sp.sin(y)
grad_f = sp.Matrix([sp.diff(f, x), sp.diff(f, y)])
H = sp.hessian(f, (x, y))
print(grad_f)
print(H)
print(grad_f.subs({x: 2, y: 0}))

For \(f(x,y)=x^2y+\sin y\), the gradient is \((2xy,x^2+\cos y)\) and the Hessian is \(\begin{pmatrix}2y&2x\\2x&-\sin y\end{pmatrix}\). The code should reproduce these expressions. SymPy’s lambdify converts a symbolic expression into a numerical function; specify NumPy when evaluating on arrays.

The chain rule and Jacobian matrices

For \(\boldsymbol{F}(u,v)=(u^2-v,uv)\), the Jacobian is \[D\boldsymbol{F}(u,v)=\begin{pmatrix}2u&-1\\v&u\end{pmatrix}.\]

PythonDownload
u, v = sp.symbols("u v")
F = sp.Matrix([u**2 - v, u*v])
J = F.jacobian([u, v])
print(J)
print(J.det())

The determinant \(2u^2+v\) measures local oriented area scaling. It may be zero where the mapping loses local invertibility. The Jacobian matrix is a derivative, not merely a table of numbers: identify the input and output variables and their order.

Chapter 1 laboratory: vector geometry and projections

Let \(\boldsymbol{a}=(2,-1,4)\) and \(\boldsymbol{b}=(1,3,-2)\). The projection of \(\boldsymbol{a}\) onto \(\boldsymbol{b}\) is \[\operatorname{proj}_{\boldsymbol{b}}\boldsymbol{a}=\frac{\boldsymbol{a}\cdot\boldsymbol{b}}{\boldsymbol{b}\cdot\boldsymbol{b}}\boldsymbol{b}.\] The cross product gives a normal vector to the plane spanned by the two nonparallel vectors.

PythonDownload
a = np.array([2., -1., 4.])
b = np.array([1., 3., -2.])
projection = (a @ b)/(b @ b)*b
normal = np.cross(a, b)
print("projection:", projection)
print("normal:", normal)
assert np.isclose(normal @ a, 0)
assert np.isclose(normal @ b, 0)

Interpretation. The projection is the component of \(\boldsymbol{a}\) parallel to \(\boldsymbol{b}\). The normal is perpendicular to the entire plane; it is not a unit normal unless divided by its magnitude.

Chapter 2 laboratory: space curves, speed, and curvature

Consider the helix \(\boldsymbol{r}(t)=(\cos t,\sin t,ct)\), where \(c>0\). Differentiation gives \[\boldsymbol{r}'=(-\sin t,\cos t,c),\qquad \boldsymbol{r}''=(-\cos t,-\sin t,0).\] Consequently, speed is \(\sqrt{1+c^2}\), curvature is \(1/(1+c^2)\), and torsion is \(c/(1+c^2)\). The arc length on \([0,2\pi]\) is \(2\pi\sqrt{1+c^2}\).

PythonDownload
t = sp.symbols("t", real=True)
c = sp.Rational(1, 2)
r = sp.Matrix([sp.cos(t), sp.sin(t), c*t])
r1, r2, r3 = r.diff(t), r.diff(t, 2), r.diff(t, 3)
cross = r1.cross(r2)
kappa = sp.simplify(sp.sqrt(cross.dot(cross)) /
                    sp.sqrt(r1.dot(r1))**3)
tau = sp.simplify(cross.dot(r3) / cross.dot(cross))
print("curvature:", kappa, "torsion:", tau)
assert sp.simplify(kappa - sp.Rational(4, 5)) == 0
assert sp.simplify(tau - sp.Rational(2, 5)) == 0

The torsion formula is valid where \(\boldsymbol{r}'\times\boldsymbol{r}''\ne\boldsymbol{0}\). Interpret curvature as bending per unit arc length and torsion as the departure from planarity.

Chapter 3 laboratory: tangent planes and approximation error

For \(f(x,y)=x^2+xy+y^2\), linearization at \((1,1)\) gives \[L(x,y)=3+3(x-1)+3(y-1).\] The difference \(f-L=(x-1)^2+(x-1)(y-1)+(y-1)^2\) is nonnegative. Compute the approximation and compare it to the exact function.

PythonDownload
def f(x, y):
    return x*x + x*y + y*y

def L(x, y):
    return 3 + 3*(x-1) + 3*(y-1)

point = (1.1, 0.9)
print("exact:", f(*point), "linear:", L(*point))
print("error:", f(*point) - L(*point))

A small error near the base point supports the local usefulness of the tangent-plane approximation, not global accuracy.

Chapter 4 laboratory: constrained optimization

Maximize \(U(x,y)=8x+6y-x^2-2y^2-xy\) subject to \(x\ge0\), \(y\ge0\), and \(2x+y\le8\). Its Hessian \(\begin{pmatrix}-2&-1\\-1&-4\end{pmatrix}\) is negative definite, so the objective is strictly concave. The feasible region is convex and compact; a feasible stationary point or boundary optimum is therefore global.

PythonDownload
from scipy.optimize import minimize

def utility(z):
    x, y = z
    return 8*x + 6*y - x*x - 2*y*y - x*y

constraints = [{"type": "ineq", "fun": lambda z: 8-2*z[0]-z[1]}]
result = minimize(lambda z: -utility(z), x0=[1., 1.],
                  bounds=[(0, None), (0, None)],
                  constraints=constraints, method="SLSQP",
                  options={"ftol": 1e-12})
assert result.success
assert 2*result.x[0] + result.x[1] <= 8 + 1e-8
print("allocation:", result.x, "utility:", utility(result.x))

A solver success flag is not a proof. Verify feasibility, compare relevant boundaries, and use concavity to justify global optimality.

Chapter 5 laboratory: multiple integration and Monte Carlo

Consider the triangular region \(D=\{(x,y):0\le x\le1,\ 0\le y\le1-x\}\) and \(f(x,y)=x+y\). The exact integral is \[I=\int_0^1\int_0^{1-x}(x+y)\,\mathrm{d}y\,\mathrm{d}x=\frac13.\]

PythonDownload
from scipy.integrate import dblquad
I, estimated_error = dblquad(lambda y, x: x+y,
                              0, 1, lambda x: 0,
                              lambda x: 1-x)
print("quadrature:", I, "estimated error:", estimated_error)
assert np.isclose(I, 1/3)

rng = np.random.default_rng(2026)
n = 100000
x = rng.uniform(0, 1, n)
y = rng.uniform(0, 1, n)
mc = np.mean((x+y)*(x+y <= 1))
print("Monte Carlo estimate:", mc)

The Monte Carlo method samples uniformly on the enclosing unit square and uses an indicator for membership in \(D\). The estimate approaches \(I\) as the sample size grows, but individual results vary. Always state the random seed and sample size.

Chapter 6 laboratory: circulation and Green’s theorem

Let \(\boldsymbol{F}(x,y)=(-y,x)\) and let \(C\) be the positively oriented unit circle. Parameterizing \(C\) by \((\cos t,\sin t)\) gives \[\oint_C\boldsymbol{F}\cdot\,\mathrm{d}\boldsymbol{r}=\int_0^{2\pi}1\,\mathrm{d}t=2\pi.\] Green’s theorem gives the same result because \(\partial Q/\partial x-\partial P/\partial y=2\) and the unit disk has area \(\pi\).

PythonDownload
from scipy.integrate import quad

def circulation_integrand(t):
    x, y = np.cos(t), np.sin(t)
    dx, dy = -np.sin(t), np.cos(t)
    P, Q = -y, x
    return P*dx + Q*dy

value, error = quad(circulation_integrand, 0, 2*np.pi)
assert np.isclose(value, 2*np.pi)
print("line integral:", value, "Green theorem:", 2*np.pi)

Orientation matters: reversing the direction of traversal changes the sign of the circulation. The theorem requires suitable smoothness and orientation assumptions.

Chapter 7 laboratory: spherical metrics and great circles

For a sphere of radius \(R\), use latitude \(\phi\) and longitude \(\lambda\). The line element is \[\,\mathrm{d}s^2=R^2\,\mathrm{d}\phi^2+R^2\cos^2\phi\,\mathrm{d}\lambda^2.\] The corresponding metric tensor is diagonal with entries \(R^2\) and \(R^2\cos^2\phi\). Given two points on the unit sphere with latitudes \(\phi_1,\phi_2\) and longitude difference \(\Delta\lambda\), their central angle \(\gamma\) satisfies \[\cos\gamma=\sin\phi_1\sin\phi_2+\cos\phi_1\cos\phi_2\cos(\Delta\lambda).\] The shortest spherical distance is \(R\gamma\) (subject to the usual antipodal nonuniqueness).

PythonDownload
def great_circle_distance(lat1, lon1, lat2, lon2, R=6371.0):
    p1, l1, p2, l2 = np.deg2rad([lat1, lon1, lat2, lon2])
    a = np.sin((p2-p1)/2)**2 + (
        np.cos(p1)*np.cos(p2)*np.sin((l2-l1)/2)**2)
    angle = 2*np.arctan2(np.sqrt(a), np.sqrt(max(0, 1-a)))
    return R*angle

print(great_circle_distance(0, 0, 0, 90, R=1))
assert np.isclose(great_circle_distance(0,0,0,90,R=1), np.pi/2)

The haversine-based expression is often more stable for small separations than direct inverse cosine. Earth is not exactly spherical, so this is a modeling approximation rather than an ellipsoidal geodesic calculation.

Chapter 8 laboratory: a finite-difference heat solver

For the one-dimensional heat equation \(u_t=\alpha u_{xx}\) on \(0<x<1\) with zero boundary values, an explicit forward-time, centered-space scheme is \[u_i^{n+1}=u_i^n+\mu(u_{i-1}^n-2u_i^n+u_{i+1}^n),\qquad\mu=\frac{\alpha\Delta t}{(\Delta x)^2}.\] For this standard one-dimensional scheme, \(\mu\le1/2\) is the stability restriction. With initial condition \(u(x,0)=\sin(\pi x)\), the exact solution is \(u(x,t)=e^{-\alpha\pi^2t}\sin(\pi x)\).

PythonDownload
def heat_solver(nx=80, alpha=0.1, T=0.1, mu=0.4):
    dx = 1.0/nx
    dt_target = mu*dx*dx/alpha
    steps = int(np.ceil(T/dt_target))
    dt = T/steps
    actual_mu = alpha*dt/dx**2
    assert actual_mu <= 0.5
    x = np.linspace(0, 1, nx+1)
    u = np.sin(np.pi*x)
    for _ in range(steps):
        new = u.copy()
        new[1:-1] = u[1:-1] + actual_mu*(
            u[:-2]-2*u[1:-1]+u[2:])
        u = new
    exact = np.exp(-alpha*np.pi**2*T)*np.sin(np.pi*x)
    return x, u, np.max(np.abs(u-exact))

x, numerical, error = heat_solver()
print("maximum error:", error)

A stable computation can still be inaccurate. Refine the spatial mesh, adjust the time step consistently, and compare errors against the exact solution to study convergence.

Comparing Python and R computational conventions

Task R Python
Create numeric vector c(1,2,3) np.array([1,2,3])
First component v[1] v[0]
Dot product sum(a*b) np.dot(a,b)
Matrix product A %*% B A @ B
